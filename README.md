# Make My Day

Make My Day is a tiny React web experience where the interaction is the punchline.

The product intentionally gives trivial predictions, but the click-to-reveal ritual is crafted to feel disproportionately dramatic, playful, and memorable.

## Quick Start

### Prerequisites
- Node.js 18+
- npm 9+

### Install
```bash
npm install
```

### Run locally
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

## Scripts
- `npm run dev`: Start Vite dev server
- `npm run build`: Type-check and build production bundle
- `npm run preview`: Serve built output locally

## Stack
- React 18
- TypeScript
- Vite
- Plain CSS (no UI framework)
- No backend

## Repository Layout
- `src/`: App logic, prediction engine, content catalog, and styles
- `docs/`: Product, architecture, design, content, and developer documentation
- `dist/`: Production build output
