# Design and Motion

## Visual Direction
Editorial, minimal, and playful.

The design intentionally avoids dashboard/SaaS visual language.

## Component Hierarchy
- Dominant CTA as hero object
- Reveal card as ceremonial output
- Replay as low-friction secondary action

## Typography
- Expressive display styling for high-emphasis moments
- Clean body typography for readability
- Tight control of line length and rhythm

## Motion Principles
- Motion must communicate state change or anticipation
- No confetti, random particles, or decorative bounce spam
- Keep movement restrained but unmistakable

## Primary Motion Sequence
1. Press physics on CTA
2. Anticipation phase progression
3. Card settle-in reveal
4. Typed prediction appearance
5. Replay fade-in after reveal settles

## Timing Philosophy
- Fast enough to feel responsive
- Slow enough for humor beats to be readable
- Stagger text moments so users can perceive the ritual

## Responsive Behavior
Mobile preserves the same emotional hierarchy:
- prominent CTA
- readable reveal card
- tap feedback on all interactive elements

## Accessibility
- Reduced-motion handling for users preferring minimal animation
- High-contrast text usage
- Focus-visible states for keyboard interactions

## Visual Quality Guardrails
Avoid:
- Feature-grid style cards
- Overloaded iconography
- Heavy gradients across every element
- Unclear interaction affordances
