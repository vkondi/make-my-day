# Project Guide

## Product Summary
Make My Day is a one-button digital toy designed for delight, not utility.

Users trigger a ritualized reveal sequence and receive an unexpectedly specific, witty, or wholesome prediction.

## Experience Goal
The reveal should feel much more important than the actual information being revealed.

That contrast is the core humor.

## Target Feeling
- Immediate curiosity
- Short anticipation arc
- A smile from specificity
- Desire to press again

## Scope
In scope:
- Landing state
- Primary CTA
- Ritualized anticipation
- Prediction reveal
- Replay action

Out of scope:
- Auth and profiles
- Database and backend services
- Dashboards/settings/navigation clutter
- Analytics-heavy product behavior

## Core User Journey
1. User lands on a minimal stage with one dominant action.
2. User presses CTA.
3. App enters a multi-step anticipation beat.
4. Reveal card appears with prediction and supporting meta.
5. User can replay instantly.

## Personality Principles
- Specific over generic
- Wry and self-aware, not cynical
- Warm when possible
- Surprising without becoming random nonsense

## Product Constraints
- Keep interface sparse
- Keep interactions intentional
- Avoid decorative animation with no communicative purpose
